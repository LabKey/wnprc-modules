Workflow

  1. When initially loading the page select the grid size. For larger rooms with more cages you would want to select a larger grid to ensure that all the items can be placed on the layout. This grid size cannot be changed later.
  2. Move items to the layout by dragging and dropping them in position
  3. Open an items context menu by right-clicking the item.
    1. Different items have different context menus, but they are all accessed the same way.
  4. Place cages next to each other to merge them into the same rack or connect the racks.
    1. Cages cannot be merged unless they share the same type.
    2. Generally you should create your racks before assigning them a rack type.

Context Menus

Cage context menus support the following actions

  1. Removing the cage or rack from the layout.
  2. Changing the rack.
    • In this menu you can also create new racks. Open the menu and enter the rack type and rack id, and it will be automatically assigned to that rack when you save.
  3. Changing the cage number.
  4. Rotating the rack group.
    • Rotations start at 90 degrees.
    • Rotations are done clockwise. For the starting rotation and position this means that the top of the rack group is the right side of the group.
    • Rack groups are all the cages/racks that are connected to each other.

Room Object context menus support the following actions

  1. Removing the room object from the layout.
  2. Gate objects have have two additonal actions.
    1. Set the room that the gate is connected to. This indicates that the two rooms have a connection that animals can go through.
    2. Closing/opening the gate, indicating if the gate is open or closed and if animals are able to go between rooms.

Creating Templates

Rules for creating templates

  • All racks/cages in a room must have a default rack type. By default, this is what they are when placed in the room. This ensures that real racks/cages are not placed in rooms that "do not exist."

Creating Real Rooms

Rules for creating real room layouts

  • All racks/cages in a room must have a real rack type. This ensures that racks/cages that "do not exist" are not placed in rooms that are real.
  • No duplicate cage numbers.

Additional Notes for Both Types of Layouts

Both real rooms and template rooms have a resizeable border that determines the border of the room. This helps compact the size of the layout into a more realistic room size when working with different size starting grids. Ensure that no room objects or cages are placed outside this border as they will not be shown when viewing the room from the display page.

Additional Actions

  1. The Grid Enabled button turns off the grid lines to show a better view of what the room will look like on the display page.
  2. Clear Layout wipes all the items from the layout, allowing you to start over.
